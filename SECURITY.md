# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue or data exposure in this repository:
1. Please do **NOT** open a public issue on GitHub.
2. Send a detailed report to the maintainers at the repository contact point.
3. Include steps to reproduce the issue, potential impact, and suggested mitigation.
4. Maintainers will review and respond within 48 business hours.
